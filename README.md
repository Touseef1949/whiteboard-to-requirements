# Whiteboard to Requirements — AI-Powered Sketch Analysis

> **Upload a whiteboard photo → AI asks clarifying questions → generates structured requirements & diagrams.**

[![Live App](https://img.shields.io/badge/Try%20It-Live%20App-blue?style=flat&logo=streamlit)](https://whiteboardtorequirements.streamlit.app)
[![Website](https://img.shields.io/badge/Website-touseefshaik.com-2563eb?style=flat)](https://touseefshaik.com/tools/whiteboard-to-requirements)

---

## What It Does

You sketch. AI asks. Requirements emerge.

1. **Upload** a photo of your whiteboard, notebook, or hand-drawn diagram
2. **AI analyzes** the sketch and asks clarifying questions
3. **Generates** a structured output: functional requirements, user stories, and Mermaid diagrams

Built for BAs and Product Owners who whiteboard before they document.

---

## Tech Stack

`Python` `Streamlit` `Gemini 3.5 Flash` `Agno` `Mermaid.js`

---

## Quick Start

```bash
git clone https://github.com/Touseef1949/whiteboard-to-requirements.git
cd whiteboard-to-requirements
pip install -r requirements.txt
export GOOGLE_API_KEY="...port GEMINI_API_KEY=*** streamlit run app.py
```
